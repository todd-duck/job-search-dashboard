# Answer Bank: <Your Name>

How it works:
- The skill picks the closest entry, swaps in the company name and one or two details from the posting, and keeps within the field's character limit. Under 300 characters, it uses the **Short** version.

- The setup interview writes the first set of entries for you. Edit them freely.
